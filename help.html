Help & FAQ

What is a static QR code?

A static QR code stores your content directly in the pattern. It works forever, needs no server and can't be edited after it is printed. Every code made here is static.

What is a dynamic QR code?

A dynamic code points to a short redirect link that can be changed later and can record scans. QR Studio doesn't offer dynamic codes yet.

Is it free? Do I need an account?

Yes, it is free and no account is needed.

Is my data uploaded?

No. Codes are generated in your browser. See the privacy policy.

PNG or SVG?

Use PNG for screens, documents and social media. Use SVG for print and anything that must scale without blurring.

My code won't scan. What should I check?
  • Dark code on a light background, with high contrast.
  • A quiet zone (blank border) of at least 4 modules.
  • Large enough: at least about 2 cm (0.8 in) when printed.
  • Shorter content gives a simpler code that's easier to scan.
  • Raise the error-correction level if the print may get scuffed.
How do Wi-Fi codes work?

Phones that scan the code offer to join the network. The password is stored inside the code, so anyone who can scan it can connect.

What phone number format should I use?

Use international format with a leading +, for example +14155550123. WhatsApp codes require it.

How much can a code hold?

Up to a few thousand characters, but more content means a denser code that is harder to scan. We warn you when a code gets dense.

Can I add a logo to my code?

Not yet. Logos reduce scan reliability, so we plan to add them later with safety checks.

Should I test before printing?

Yes. Scan the exported file and the physical print with more than one phone before you print in volume.
